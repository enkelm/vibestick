## Human Brief

**Category:** enhancement
**Summary:** Physically qualify the implemented target-controller input
backend, especially Share and duplicate-event suppression.

**Why this needs a human:**
The remaining evidence requires access to the target Xbox Wireless Controller
`045E:0B12` and active operation of every physical control. The controller was
not connected during triage, so an unattended coding agent cannot complete
this acceptance step.

**Current behavior:**
Commit `8d6b1c3` implements one normalized controller-event stream. Raw HID
owns lifecycle and standard controls, while Game Controller contributes Share.
Automated tests cover raw decoding, backend ownership, duplicate-state
suppression, and connection lifecycle. The application provides a
`--controller-diagnostic` workflow that reports raw, Game Controller, and
normalized events plus coverage.

**Desired behavior:**
On the target controller, the diagnostic should observe every required control,
including Share. Each physical transition should produce exactly one normalized
event, and disconnecting and reconnecting should produce the corresponding
lifecycle events.

**Key interfaces:**
- `ControllerEvent`: the normalized input and lifecycle stream consumed by the
  rest of Vibestick.
- `ControllerEventNormalizer`: assigns one production owner to each control
  and suppresses duplicate state.
- `--controller-diagnostic`: the operator workflow for comparing backend events
  with normalized output and required-control coverage.

**Acceptance criteria:**
- [ ] Connect target controller `045E:0B12` and run

- [ ] Confirm Game Controller exposes Share and record whether it exposes every
      other required control.
- [ ] Confirm each physical transition appears exactly once in normalized
      output despite events observed from multiple backends.
- [ ] Confirm disconnect and reconnect produce one normalized lifecycle event
      each.
- [ ] Record the observed result in this issue.
